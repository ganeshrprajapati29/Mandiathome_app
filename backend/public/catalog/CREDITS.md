# Image credits

The product and category photos in this folder were built from the **Fruits-360** dataset
by Mihai Oltean and Horea Mureșan (https://github.com/fruits-360, https://github.com/Horea94/Fruit-Images-Dataset),
licensed under **CC BY-SA 4.0** (https://creativecommons.org/licenses/by-sa/4.0/).

Changes: backgrounds removed, several photos combined into one image, resized and sharpened.
These derived images are shared under the same CC BY-SA 4.0 licence.
Script used: `tools/gen.py` with `tools/specs.json`.

Replace any photo from the admin panel (Products → Edit → Image) with your own shop photos at any time.
